# ByteBites Case Studies Index

> This index is written for reviewers and presentation audiences. Each case study explains one engineering decision, the failure mode it solved, and what it proves about ByteBites as a product.

## How to Read These Cases

ByteBites is not a single feature project. The system became convincing because multiple layers were hardened together:

- **Foundation**: modernization, security cleanup, migrations, deployment.
- **Data**: crawler reliability, coverage audits, taxonomy, reviews, media.
- **AI**: streaming, model selection, semantic search, dialogue state, evaluation.
- **Product**: recommendation framing, Web/LINE booking sync, parking reminders, premium UI positioning.

In the presentation, the strongest path is:

```text
Data quality -> AI reliability -> transaction consistency -> product differentiation
```

## 中文導讀

這些案例不是流水帳，而是展示「工程判斷」。建議報告時不要逐篇朗讀，而是挑 4 條主線：

1. **資料不是背景，是 AI 品質的天花板**  
   600 家 active Taipei shops、media coverage、ABSA、Qdrant payload、legacy seed cleanup，證明推薦不是靠模型硬猜。

2. **AI 不是聊天，是任務狀態機**  
   使用者會說「第 2 家」「明天晚上」「改 8 點」「取消剛剛那筆」，所以系統需要 recommendation context、booking draft、confirmation policy。

3. **Web 和 LINE 是同一個交易流程**  
   訂位、付款、取消、候補、停車提醒都回到後端狀態，不讓 Web 和 LINE 各自說各自的。

4. **產品定位不是模仿競品**  
   ByteBites 走的是「AI 會推薦，也會安排」：推薦只是入口，後面的訂位、提醒、停車才是差異化。

5. **作品要能被審查，不只要能展示**
   單一 verification script、CI matrix、data quality gate 和 evidence map 讓 reviewer 能把主張連回程式、測試與資料。

## Reviewer Questions This Index Helps Answer

- Is this only a UI prototype?
  No. The cases show backend migrations, identity sync, tests, AI contracts, data pipelines, and deployment.

- Is the AI reliable or just fluent?
  Reliability is addressed through hard constraints, state handling, regression tests, and response contracts.

- Is the data real enough to support recommendations?
  The crawler and coverage cases show how shop, review, media, taxonomy, and vector payload quality were audited.

- Is the product differentiated?
  The parking, LINE sync, and AI operations positioning cases show why ByteBites is more than restaurant discovery.

- Can I verify the claims quickly?
  Yes. Start with `README.md`, then run `scripts/verify-portfolio.sh`.
